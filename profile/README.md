# Rowset LLC

Rowset is a small software and data company in Georgia, US. We test AI systems against answers fixed in advance, and we build data tools that keep track of where every value came from. Website: [rowset.co](https://rowset.co) · Papers: [rowset.co/papers](https://rowset.co/papers)

## Research code and data

| Repository | What it is |
|---|---|
| [false-credit-pilots](https://github.com/Rowset-LLC/false-credit-pilots) | Do AI research agents take credit for changes that did nothing? Four small pilots with known answers. |
| [known-answer-construction](https://github.com/Rowset-LLC/known-answer-construction) | Code and results for the ML4PS 2026 workshop paper "Known-answer construction for agent-written analysis code". |
| [lost-warnings](https://github.com/Rowset-LLC/lost-warnings) | Do Wikipedia's doubt tags reach AI answers? Code, data and a loader that keeps the tags. |
| [map-and-workspace](https://github.com/Rowset-LLC/map-and-workspace) | Code for two Gemma 4 Developer Agent Paper Track papers. |

## Tools

- [pipeline-reconcile](https://github.com/mark124/pipeline-reconcile): a Claude Code plugin that checks the records a data pipeline reported as delivered actually arrived.
- [dreaming](https://github.com/mark124/dreaming): a Claude Code plugin that keeps Claude's memory notes true to what happened in your own past sessions.
